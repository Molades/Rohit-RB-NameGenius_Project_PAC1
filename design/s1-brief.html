Decisions made against the direction, not defaults:
— Name is the only field with the ink-bordered hero bar and merged action, echoing the single-field search pattern in the reference set; it's the one thing on this screen sized to be found in one glance.
— TLD sits as quiet chips directly under the hero bar (not stacked as a labeled field like the rest) because it modifies the primary action rather than adding brief context.
— Description and Competitors sit below a rule, in the card's quiet border-border/12px treatment, with no merged action of their own — they read as supplied context, not as more steps to complete. The character count against Description makes the ~1,000-char budget visible without adding a warning color.
— One entry action total (in the hero bar). No second "Find names" button at the bottom — a stacked form defaults to a bottom CTA; this direction doesn't.
